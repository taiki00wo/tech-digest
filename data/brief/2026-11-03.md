### honojs/hono v4.13.16 | https://github.com/honojs/hono/releases/tag/v4.13.16
Security fixes
This release includes fixes for the following security issues:
`mount()` and `app.mount()` can forward a path that bypasses middleware scoped inside the mount prefix
Affects: `mount()` in `hono/mount` and `app.mount()`. A dynamic prefix such as `/api/:tenant/*` was removed by the length of the route pattern. The forwarded path was also re-normalized by the URL parser, so a decoded `\` became `/` and `..` collapsed. Both let a crafted request skip middleware scoped inside the mount prefix. Routes such as `/assets*` and duplicate parameter names now throw. GHSA-4m76-xfj5-7975
RegExpRouter skips wildcard middleware for certain route patterns and for paths with an encoded line
